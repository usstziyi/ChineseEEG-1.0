### 📝 关键说明

*   **数据关系**：`ChineseEEG-2` 是 `ChineseEEG` 的扩展和升级版本。`ChineseEEG` 主要聚焦于**默读**任务，而 `ChineseEEG-2` 则增加了**朗读**和**听书**两种新任务，实现了多模态数据的对齐。
*   **获取数据**：**Science Data Bank** 是两个数据集主要的下载平台。`ChineseEEG` 有两个发布渠道，`ChineseEEG-2` 则强烈建议使用官方维护的最新版本。
*   **代码仓库**：两个数据集的代码分别托管在独立的 GitHub 仓库中，是理解实验设计和进行数据分析的重要参考。

**请注意**：这些数据集对存储空间有一定要求（例如，`ChineseEEG` 在 OpenNeuro 上约 697 GB），下载前请确保有足够的空间。
